# Kritan Duwal — Portfolio

Portfolio site for my audio engineering, DSP and software work: spatial audio research, plugins and measurement, recording, mixing and mastering. It is built around listening, with level-matched A/B players for every before/after comparison and an in-browser version of my Hybrid Pan Mixer.

Some mixing examples and the default mixer stems use multitracks from the [Cambridge-MT library](https://www.cambridge-mt.com/ms3/mtk/), used for educational purposes.
